Privasi & Keamanan Data

Bagaimana Generate Soal Ujian menjaga data Anda.

Generate Soal Ujian menghargai privasi pengguna. Aplikasi ini dirancang agar seluruh data soal yang Anda buat tetap berada di bawah kendali Anda — tersimpan secara lokal di perangkat, tanpa dikirim ke server mana pun secara otomatis.

Keamanan Data

Aplikasi berjalan sepenuhnya di browser Anda. Isi soal, gambar, dan pengaturan dokumen tidak dikirim ke server secara otomatis — tidak ada akun, tidak ada pelacakan isi dokumen. Jangan menyimpan informasi pribadi atau data sensitif yang tidak diperlukan di dalam soal.

Penyimpanan Lokal

Seluruh file soal disimpan menggunakan localStorage browser, sehingga data tetap tersedia ketika halaman direfresh atau browser ditutup lalu dibuka kembali. Perlu diperhatikan:

  • Data terikat pada browser dan perangkat yang Anda gunakan saat ini.
  • Data tidak otomatis berpindah ke browser atau perangkat lain.
  • Menghapus data browser (cache / site data) dapat menghapus seluruh data yang tersimpan secara lokal.

Kontrol Pengguna

Anda adalah pemilik penuh atas data Anda. Anda dapat membuka, mengubah nama, menduplikat, dan menghapus file soal kapan saja melalui halaman Bank Soal. Untuk data yang penting, Anda bertanggung jawab melakukan backup — misalnya dengan mengekspor lembar soal ke PDF secara berkala.

Penghapusan Data

Menghapus file soal di Bank Soal akan menghapusnya secara permanen dari perangkat. Anda juga dapat menghapus seluruh data lokal aplikasi sekaligus melalui tombol di bawah ini. Data yang telah dihapus tidak dapat dikembalikan.

Zona Berbahaya

Menghapus semua data akan membersihkan seluruh file soal dan pengaturan yang tersimpan di perangkat ini.

Cara Menggunakan BuatSoal

Alur singkat membuat lembar soal dari awal sampai siap diekspor.

1
Tambah soal

Di halaman Beranda, klik kartu "Pilihan Ganda" atau "Essay" untuk membuka form tambah soal.

2
Isi detail soal

Tulis pertanyaan. Untuk pilihan ganda, tambahkan gambar (opsional), atur jumlah pilihan A–Z, ukuran gambar, dan layout 1 atau 2 kolom. Klik "Selesai" untuk menyimpan.

3
Kelola daftar soal

Soal yang tersimpan muncul di panel "Daftar Soal". Gunakan tombol Edit, Duplikat, Hapus, atau panah ↑/↓ untuk mengatur urutan.

4
Cek preview

Panel "Preview Lembar Soal" menampilkan hasil akhir dalam format A4. Gunakan tombol zoom untuk memperbesar/memperkecil tampilan, dan toggle Desktop/Mobile untuk melihat mode tampilan.

5
Ekspor PDF

Jika sudah sesuai, klik "Ekspor PDF" untuk mengunduh file lembar soal Anda.
